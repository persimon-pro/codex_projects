# LOFT CREATIVE HOUSE

## Новая версия: LOFT Cinema

Главная с одной непрерывной трёхмерной композицией: **фотоаппарат → микрофон → ноутбук → значок Instagram**. Предметы собираются из процедурной геометрии Three.js и плавно меняют форму. Вокруг вращающейся модели проходят две тонкие шампанские орбиты; на тёмном студийном фоне видны редкие звёзды и мягкая нижняя тень. Оформление сцены воссоздано по предоставленному кадру: точный исходник указанного старого Vercel-деплоя в локальной истории не найден. В начале последовательность движется автоматически; прокрутка передаёт управление пользователю. В сцене оставлен только крупный RU/EN-заголовок: мелкие подписи, описания, CTA, переключатели, счётчики и бегущая строка удалены. Плавающий чат появляется после выхода из главного блока.

Для паузы без видимой панели управления выберите сцену клавишей Tab и нажмите **Пробел**; повторное нажатие продолжает движение. Системное `prefers-reduced-motion` отключает автоматические превращения и оставляет управление прокруткой.

Анимации подключены через npm и собираются локально: **Three.js** рисует объёмные предметы и переходы, **GSAP** раскрывает главный заголовок и карточки, **ScrollTrigger** добавляет параллакс медиа при прокрутке, **Lenis** — плавную прокрутку колёсиком. Интеграция находится в `src/animation-system.js`, эффекты разделов — в `src/scroll-effects.js`. Прокрутка окон чата и модальных окон сохраняет нативное поведение. CDN для библиотек не требуется.

Предыдущая версия со скульптурами сохранена на `/sculpture` (`sculpture.html`). Основной бренд, RU/EN, тарифы, кейсы, страницы услуг, букинг, заявка и существующий AI-помощник сохранены. Для новой композиции кейсы перемещены перед услугами и тарифами.

Проверенный запуск на Node.js 24:

```bash
cd /workspace/codex_projects/loft-design-lab
npm ci
PORT=3003 npm start
```

`npm start` и `npm run dev` автоматически собирают оба варианта перед запуском. Отдельная сборка: `npm run build`. Результаты `assets/js/loft-cinema.js`, `assets/js/loft-cinema.css`, локальные шрифты и `assets/js/loft-experience.js` генерируются из `src/` и не хранятся в Git; для статического хостинга сначала выполните сборку.

Ключевые файлы: `loft-cinema.css`, `src/loft-cinema.js` (управление последовательностью), `src/device-morph-scene.js` (3D-предметы и превращения), `assets/images/cinema/{camera,microphone,laptop,instagram}.svg` (статичные резервные изображения). Внешние модели, AI-сервис и сторонние текстуры для просмотра не требуются. Шрифты локальные. Сохранённая скульптурная версия использует `loft-3d.css`, `src/loft-experience.js` и `src/loft-scene.js`.

При `prefers-reduced-motion` нет автоматического движения: прокрутка продолжает выбирать предмет. При отсутствии WebGL остаются SVG-предметы, статичные орбиты, заголовок и основная навигация сайта. Рендеринг останавливается на паузе, вне экрана и в скрытой вкладке. Вращение не пересчитывает геометрию неподвижной формы; повторяющиеся детали объединены в два инстансных набора. На медленной графике разрешение сцены снижается автоматически, сохраняя чёткость текста.

При отключённом или заблокированном JavaScript статичное изображение, заголовок и остальные разделы остаются видимыми. Экран загрузки включается только работающим скриптом и дополнительно скрывается через CSS через четыре секунды, если дальнейшая инициализация прервалась. Запрет localStorage не мешает загрузке и переключению языка.

`npm run test:e2e` запускает браузерные проверки desktop/mobile: реальный WebGL, четыре разных предмета по пикселям, закрепление сцены, управление прокруткой, клавиатурная пауза, reduced motion, отсутствие WebGL, сохранённая версия, языки, тарифы, портфолио, страницы услуг, бриф и локальный AI-ответ. В облачной среде используется системный Chromium. На другой машине установите его командой `npx playwright install chromium`. Тесты не отправляют заявки в Telegram.

`npm run preview:export` создаёт автономный `preview/loft-preview.html` со встроенными изображениями, шрифтами и скриптами. Ролики команды заменены статичными постерами, чтобы уменьшить размер файла; на основном сайте видео сохранены. Переходы на серверные страницы и чат в этом просмотре заменены подсказкой.

Открывайте сам HTML-файл в актуальном Chrome, Edge, Firefox или Safari. Для объёмных превращений нужны разрешённый JavaScript и WebGL. Встроенный просмотрщик чата или файлов может запрещать скрипты и показывать только статичную версию. Обычная ссылка на путь внутри облачной среды не гарантирует скачивание файла через этот чат; для публичной ссылки нужно отдельно разместить сайт.

Для разработки ключи не требуются: AI-помощник использует предусмотренный проектом локальный резервный режим. Доставка реальных заявок требует `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; внешний LLM — ключа выбранного провайдера. В текущей среде этих ключей нет, доставка Telegram и внешний LLM не проверены.

## 🔤 Шрифты (Oswald)

Сохранённые страницы используют **Oswald** (начертания от ExtraLight 200 до Bold 700) с полной поддержкой кириллицы и латиницы. Новая главная использует локальные **Manrope** и **Cormorant Garamond**, которые включаются в сборку.

- **Для дизайнеров / работы в Figma / Photoshop / Illustrator:**
  Откройте папку `fonts/desktop/` и установите файлы `.ttf` в систему (двойной клик на macOS или правой кнопкой -> Установить в Windows).
- **Для автономной работы сайта:**
  В `styles.css` уже подключен локальный `fonts/fonts.css`, использующий сжатые `.woff2` шрифты из папки `fonts/web/`. Сайт работает полностью офлайн без обращения к серверам Google.

## 🚀 Запуск проекта

### 1. Быстрый просмотр в браузере (только статика)
Сначала установите зависимости и соберите браузерные файлы, затем запустите локальный HTTP-сервер из корня проекта:
```bash
npm ci
npm run build
python3 -m http.server 8080
```

Для страниц с чистыми URL, чата и заявок используйте `npm start`. Для просмотра без локального сервера создайте автономный HTML командой `npm run preview:export` и откройте `preview/loft-preview.html` в браузере.

### 2. Запуск с бэкендом и Telegram-ботом заказов
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. Укажите токен вашего Telegram-бота в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```
4. Запустите сервер:
   ```bash
   npm start
   ```
   Сервер запустится на `http://localhost:3000`.

5. Чтобы получать заявки с сайта в Telegram:
   - Найдите вашего бота в Telegram и отправьте команду `/start`.
   - Теперь любые заявки с формы на странице `/order` будут моментально приходить вам в личные сообщения Telegram!

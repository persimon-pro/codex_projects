# LOFT CREATIVE HOUSE

## Новая версия: LOFT Cinema

Главную открывает короткая фирменная заставка: мелкие частицы тёплого белого и шампанского собираются по альфа-маске настоящего логотипа `assets/images/logo_rect_white.png`, затем сменяются чётким оригиналом. Модуль `src/logo-intro.js` использует Canvas 2D, а `logo-intro.css` оформляет композицию. Тяжёлая WebGL-сцена запускается после вступления. Заставку можно пропустить кнопкой или Escape; reduced motion, прямые ссылки на разделы и ошибки ресурсов не блокируют навигацию. Проверки заставки находятся в `tests/logo-intro.spec.js`.

### Живая материя

На главной появилась интерактивная скульптура: три настоящие геометрические формы ORBIT / FLUX / SIGNAL плавно превращаются друг в друга. Процедурная студия отражается в металле; форму можно вращать мышью или горизонтальным жестом на телефоне, менять энергию и ставить движение на паузу. Вертикальная прокрутка остаётся нативной. Модели и окружение создаются локально без внешних загрузок. Секция и её управление сохраняются при недоступном WebGL.

Общая система движения связывает главную и страницы услуг: пословное освещение манифеста, параллакс кейсов, контекстный курсор портфолио, свет на карточках, упругие стрелки, раскрытие портретов и логотипов, движение орнамента, типографика контактов и лента, реагирующая на скорость прокрутки. Бриф показывает заполнение четырёх групп полей, не изменяя логику отправки. Главная реагирует на курсор оптической линзой.

Новые модули: `src/liquid-sculpture.js`, `src/site-choreography.js`, `src/loft-pages.js`; оформление — `liquid-sculpture.css` и `site-choreography.css`. Сборка теперь генерирует также `assets/js/loft-pages.js` и `assets/js/loft-pages.css`. Общие анимации отключаются при `prefers-reduced-motion`, включая изменение настройки во время просмотра. Скульптура останавливается за пределами экрана, в скрытой вкладке и по кнопке паузы. При ограниченном графическом ускорении разрешение главной адаптируется; типографика остаётся чёткой.

Дополнительные проверки в `tests/motion-experience.spec.js` покрывают формы и энергию скульптуры, резервный режим, настройку движения, страницы услуг и заполнение брифа без реальной отправки.

Кинематографичная главная с тремя авторскими AI-образами: обсидиановый металл, золотая волна и светлая архитектура. Изображения перетекают друг в друга через WebGL-деформацию и смешивание. В начале сцена медленно движется автоматически; прокрутка передаёт управление пользователю. Кнопки глав выбирают точную сцену, пауза останавливает автоматическое движение.

Анимации подключены через npm и собираются локально: **Three.js** рисует стеклянную волну между изображениями с рефракцией и световой гранью, **GSAP** раскрывает заголовки и карточки, **ScrollTrigger** добавляет параллакс медиа при прокрутке, **Motion** управляет магнитным движением кнопок и стрелками, **Lenis** — плавной прокруткой колёсиком. Движение курсора добавляет глубину главной сцене и наклон со световым бликом карточкам. Новых текстовых подписей для эффектов нет.

Интеграция находится в `src/animation-system.js`, эффекты разделов — в `src/scroll-effects.js`. При `prefers-reduced-motion` плавная прокрутка, параллакс, магнитные эффекты и раскрытия отключаются; переход к сцене остаётся мгновенным. Прокрутка окон чата и модальных окон сохраняет нативное поведение. CDN для библиотек не требуется.

Предыдущая версия со скульптурами сохранена на `/sculpture` (`sculpture.html`). Основной бренд, RU/EN, тарифы, кейсы, страницы услуг, букинг, заявка и существующий AI-помощник сохранены. Для новой композиции кейсы перемещены перед услугами и тарифами.

Проверенный запуск на Node.js 24:

```bash
cd /workspace/codex_projects/loft-design-lab

PORT=3003 npm start
```

`npm start` и `npm run dev` автоматически собирают оба варианта перед запуском. Отдельная сборка: `npm run build`. Результаты `assets/js/loft-cinema.js`, `assets/js/loft-cinema.css`, локальные шрифты и `assets/js/loft-experience.js` генерируются из `src/` и не хранятся в Git; для статического хостинга сначала выполните сборку.

Ключевые файлы новой версии: `loft-cinema.css`, `src/loft-cinema.js` (управление историей), `src/image-morph-scene.js` (шейдер перехода), `assets/images/cinema/*.webp` (три подготовленных AI-изображения). Изображения занимают суммарно около 400 КБ; сетевой AI-сервис для просмотра не требуется. Шрифты также локальные. Старая версия использует `loft-3d.css`, `src/loft-experience.js` и `src/loft-scene.js`.

При `prefers-reduced-motion` нет автоматического движения и деформации: прокрутка и выбор глав продолжают работать через спокойное смешивание. При отсутствии WebGL остаются статичные изображения и навигация. Рендеринг останавливается вне экрана и в скрытой вкладке. При медленной отрисовке разрешение WebGL снижается автоматически; текст и элементы управления сохраняют исходную чёткость.

При отключённом или заблокированном JavaScript статичное изображение, заголовок и остальные разделы остаются видимыми. Экран загрузки включается только работающим скриптом и дополнительно скрывается через CSS через четыре секунды, если дальнейшая инициализация прервалась. Запрет localStorage не мешает загрузке и переключению языка.

`npm run test:e2e` запускает браузерные проверки desktop/mobile: реальный WebGL, разные кадры по пикселям, закрепление сцены, управление главами, пауза, reduced motion, отсутствие WebGL, сохранённая версия, языки, тарифы, портфолио, страницы услуг, бриф и локальный AI-ответ. В облачной среде используется системный Chromium. На другой машине установите его командой `npx playwright install chromium`. Тесты не отправляют заявки в Telegram.

`npm run preview:export` создаёт автономный `preview/loft-preview.html` со встроенными изображениями, шрифтами и скриптами. Ролики команды заменены статичными постерами, чтобы уменьшить размер файла; на основном сайте видео сохранены. Переходы на серверные страницы и чат в этом просмотре заменены подсказкой.

Открывайте сам HTML-файл в актуальном Chrome, Edge, Firefox или Safari. Для морфинга нужны разрешённый JavaScript и WebGL. Встроенный просмотрщик чата или файлов может запрещать скрипты и показывать только статичную версию. Обычная ссылка на путь внутри облачной среды не гарантирует скачивание файла через этот чат; для публичной ссылки нужно отдельно разместить сайт.

Для разработки ключи не требуются: AI-помощник использует предусмотренный проектом локальный резервный режим. Доставка реальных заявок требует `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; внешний LLM — ключа выбранного провайдера. В текущей среде этих ключей нет, доставка Telegram и внешний LLM не проверены.

Сохранённые страницы используют **Oswald** (начертания от ExtraLight 200 до Bold 700) с полной поддержкой кириллицы и латиницы. Новая главная использует локальные **Manrope** и **Cormorant Garamond**, которые включаются в сборку.

## 🚀 Запуск проекта

### 1. Быстрый просмотр в браузере (только статика)
Сначала установите зависимости и соберите браузерные файлы, затем запустите локальный HTTP-сервер из корня проекта:
```bash
npm ci
npm run build
python3 -m http.server 8080
```

Для страниц с чистыми URL, чата и заявок используйте `npm start`. Для просмотра без локального сервера создайте автономный HTML командой `npm run preview:export` и откройте `preview/loft-preview.html` в браузере.

### 2. Запуск с бэкендом и Telegram-ботом заказов
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. Укажите токен вашего Telegram-бота в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```
4. Запустите сервер:
   ```bash
   npm start
   ```
   Сервер запустится на `http://localhost:3000`.

5. Чтобы получать заявки с сайта в Telegram:
   - Найдите вашего бота в Telegram и отправьте команду `/start`.
   - Теперь любые заявки с формы на странице `/order` будут моментально приходить вам в личные сообщения Telegram!

# Копия исходного LOFT в новом дизайне

Сборка подготовлена в `loft-design-lab` для локального просмотра и последующего сравнения на отдельном тестовом адресе `codex-projects-seven.vercel.app`. Подключение рабочего домена и изменение исходного сайта не выполнялись.

## Источник

- Репозиторий: `persimon-pro/loft-creative-house`.
- Проверенный `main`: `9eae9fe5a185f548921d98eb80909554397650a7`.
- Дата фиксации: 26 октября 2026 года.
- В `migration/source-manifest.json` сохранены контрольные суммы всех 132 исходных файлов, а также содержимое и SEO-параметры семи страниц.

Исходный репозиторий используется только для чтения. Доступ среды к `loft.tj` ограничен, поэтому соответствие этой версии реально опубликованному деплою домена пока не подтверждено. Источником сборки является указанный коммит, а не результат обхода живого сайта.

## Что сохранено

| Адрес | Содержимое |
| --- | --- |
| `/` | Главная, направления, портфолио, тарифы, клиенты, команда и контакты |
| `/production` | Видеопродакшн |
| `/smm` | SMM и маркетинг |
| `/branding` | Брендинг и айдентика |
| `/web` | Разработка сайтов и приложений |
| `/booking-stars` | Букинг артистов, состав артистов и ссылки на заявку |
| `/order` | Исходная форма заявки и предзаполнение по ссылкам |

Сохранены исходные тексты на русском и английском с одним согласованным изменением H1 главной: «Усиливаем бренды.» / «Brands, amplified.» вместо прежнего длинного заголовка. Адреса, якоря, ссылки, поля форм, заголовки страниц, метатеги, canonical, Open Graph, Twitter Card и JSON-LD остаются исходными. Исходные медиафайлы, шрифты, логотипы, API, базовые стили, `robots.txt` и `sitemap.xml` контролируются по исходным хешам.

Изменение первого заголовка записано отдельно в `migration/content-overrides.json`: разрешены только четыре точные замены текстовых фрагментов в H1, двух языковых блоках и текстовых узлах главной. Неизменённый `migration/source-manifest.json` хранит оригинальный заголовок для сравнения; прежний текст не добавлялся в скрытую разметку страницы.

Главная использует три новых AI-фона, заставку с рисованием логотипа, бесшовную строку, осветление манифеста и отдельную сцену фотоаппарат → микрофон → ноутбук → Instagram. Внутренние страницы получили общие цвета, типографику и анимации новой версии. Исходные фон главной и другие материалы остались в проекте. Порядок некоторых блоков и декоративные элементы соответствуют новому дизайну; остальное исходное содержимое сохранено.

## Индексация тестовой версии

В HTML восстановлены исходные производственные SEO-настройки. Поверх них **сохраняется тестовый запрет индексации** через `X-Robots-Tag: noindex, nofollow` в `server.js` и `vercel.json`. Этот заголовок ограничивает индексацию даже при исходном `index, follow` в HTML. Снятие ограничения и публикация на рабочем домене — отдельный следующий этап.

Сохранено перенаправление исходного домена `loft.tj` на `www.loft.tj`; при локальном просмотре на `localhost` оно не срабатывает. Секреты и рабочие учётные данные не переносились в снимок.

## Повторяемая проверка

```sh
python3 scripts/check-source-parity.py
npm run build
npx playwright test tests/source-parity.spec.js
```

Статическая проверка работает по сохранённому манифесту, без доступа к исходному репозиторию. Она проверяет наличие файлов, точность исходных материалов и API, SEO, заголовки, JSON-LD, ссылки, якоря, формы, 1002 языковых блока и все значимые текстовые узлы тела страниц, включая одноязычные описания и FAQ. Проверка учитывает ровно одно согласованное изменение H1 главной и отдельно сообщает его количество; остальные требования к исходному содержимому остаются строгими. Технические скрипты, SVG и прежний временный экран загрузки из текстовой сверки исключены. Перезапись манифеста допускается только явной командой `--record-source` с отдельно проверенным исходником.

HTTP/браузерные проверки проверяют семь адресов и тестовый запрет индексации, перенаправление на основной адрес домена, русскую и английскую вёрстку всех страниц, переход из букинга в форму заявки и сохраняют кадры семи страниц на компьютере и телефоне. Проверка перенаправления выполняется локально без обращения к рабочему домену. Заявки и сообщения во время этих проверок не отправляются.

## Для следующего этапа

Следующее сравнение должно отдельно проверить живой `loft.tj`, полноту маршрутов и контента, удобство новой версии, мобильную скорость и поисковые показатели. Текущая сверка подтверждает сохранение зафиксированного исходника; она не измеряет позиции в поиске и не гарантирует неизменность трафика после будущего переноса.

## Подготовка переноса 28 октября 2026

Повторная техническая проверка и локальное мобильное сравнение записаны в `migration/seo-audit-2026-10-28-technical.md`, `migration/seo-audit-2026-10-28-performance.md` и `migration/seo-audit-2026-10-28-release.md`. Лабораторные измерения сохранены отдельно от фактов о живом домене.

Для проверки рабочего профиля подготовлен отдельный генератор:

```sh
npm ci
npm run release:prepare
npm run release:check
```

Команды создают и проверяют локальную папку `release/loft-production`, не публикуют сайт и не меняют DNS. Обычная сборка и существующий тестовый адрес сохраняют `noindex`. В кандидате индексация разрешена только основному адресу `www.loft.tj`; другие хосты закрывает отдельная конфигурация и серверная политика. Шаблон проверяется официальной схемой Vercel, но реальные ответы CDN перед переносом нужно проверить отдельно.

В рабочем кандидате убрана только FAQ-разметка главной, вопросы которой отсутствуют в видимом содержимом; исходный снимок и разметка FAQ страницы букинга сохранены. До переключения остаются обязательными проверка живых URL и заголовков, настроек хостинга/DNS/TLS, привязок доставки заявок и способа отката.
